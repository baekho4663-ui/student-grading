# 수행평가 채점 도우미

학생 **1명**의 답안으로 시험하는 기본 버전입니다. 윈도우 PC에서 웹 브라우저로 사용합니다.

- 문항별 문제·배점·채점기준·필수 요소 입력
- 답안 사진 여러 장 업로드 (JPG/PNG, 합계 20MB 이하, 한 장당 2,500만 화소 이하)
- AI 점수 제안, 필수 요소별 충족 여부·증거 확인
- 교사 수정 및 최종 확정 (수정하면 재확정 필요)
- 교사 관찰과 확정 평가를 바탕으로 세특 초안 생성·수정
- 최초 제안과 교사 확정 결과를 함께 엑셀로 다운로드

## 1. 윈도우에서 처음 실행하기

1. [Python 공식 사이트](https://www.python.org/downloads/windows/)에서 **Python 3.12**를 설치합니다. 설치 첫 화면의 **Add python.exe to PATH**를 체크합니다.
2. 이 저장소의 파일을 PC에 다운로드하고 ZIP이라면 압축을 풉니다. `app.py`, `requirements.txt`, `start.bat`가 같은 폴더에 있어야 합니다.
3. `start.bat`를 더블 클릭합니다. 처음에는 인터넷에서 필요한 패키지를 설치하므로 잠시 기다립니다.
4. 브라우저가 열리면 사용합니다. 자동으로 열리지 않으면 실행 창에 표시된 Local URL을 브라우저에 입력합니다.
5. 사용하는 동안 검은 실행 창을 닫지 마세요. 종료할 때 실행 창에서 `Ctrl+C`를 누릅니다.

Python을 설치했는데 `py`를 찾지 못한다면 설치 프로그램에서 Python Launcher도 설치한 뒤 다시 시도하세요.

직접 실행하려면 해당 폴더에서 명령 프롬프트를 열어 다음을 한 줄씩 입력합니다.

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py
```

## 2. API 키 없이 먼저 시험하기

1. 왼쪽의 **체험 모드**를 유지합니다.
2. 예시 광합성 문제와 채점기준을 확인합니다. 문항 수를 늘리거나 내용을 바꿀 수 있습니다.
3. 사진을 올려 미리보기를 확인하거나, 사진 없이 **체험 결과 만들기**를 누릅니다.
4. 체험용 점수는 모두 **0점**, 필수 요소는 모두 **확인 불가**입니다. **사진을 읽거나 채점한 결과가 아닙니다.** 교사가 점수, 근거, 요소별 증거를 바꿔 보세요.
5. 검토 확인란을 체크하고 **교사 최종 확정**을 누릅니다.
6. 교사 관찰 기록을 입력한 뒤 **세특 초안 만들기**를 누릅니다. 체험 모드에서는 실제 AI 대신 관찰 기록을 포함한 편집용 템플릿이 나옵니다.
7. 세특을 수정하고 **확정 결과 엑셀 다운로드**를 누릅니다. 세특 없이 채점 결과만 내려받을 수도 있습니다.

## 3. 실제 AI 연결하기 (OpenAI API)

ChatGPT 구독과 API 요금은 별개입니다. 사용 가능한 API 결제/잔액이 필요합니다.

1. [OpenAI API 플랫폼](https://platform.openai.com/)에서 계정의 결제 설정과 API 키 발급 메뉴를 확인합니다.
2. 앱 왼쪽의 채점 방식을 **실제 AI 채점**으로 바꿉니다.
3. **OpenAI API 키** 칸에 발급받은 키를 입력합니다. 비밀번호처럼 가려지며 앱이 파일로 저장하지 않습니다.
4. 기본 모델은 `gpt-4.1-mini`입니다. 계정에서 사용할 수 있는 **이미지 입력 및 구조화 출력 지원 모델**을 사용하세요. 사용 가능 여부와 가격은 제공업체 문서에서 확인합니다.
5. 학생 이름·학번 등 개인정보를 사진에서 가리고, 학교 지침에 따른 이용 권한을 확인한 뒤 외부 전송 확인란을 체크합니다.
6. 문제·배점·채점기준·필수 요소를 작성하고 선명한 답안 사진을 올립니다. **AI 채점 제안 받기**를 누릅니다.
7. 문항별 점수와 필수 요소의 근거를 사진과 대조합니다. 오독·누락은 교사가 수정합니다. 읽기 어려운 글씨와 그림은 특히 주의하세요.
8. 최종 확정 후 관찰 기록을 입력해 세특 초안을 생성합니다. 실제 관찰과 다른 내용이 없는지 반드시 검토·수정합니다.

키를 실행할 때마다 입력하기 싫다면 `.env.example`을 복사하여 같은 폴더에 `.env`라는 이름으로 저장합니다. 메모장으로 아래처럼 편집한 뒤 앱을 재시작합니다. 파일명이 `.env.txt`가 되지 않도록 탐색기에서 파일 확장명을 표시하세요.

```dotenv
OPENAI_API_KEY=여기에_본인의_API_키
OPENAI_MODEL=gpt-4.1-mini
```

`.env`는 PC에 남는 비밀 파일입니다. 공유하거나 Git에 올리지 마세요. 이 프로젝트의 `.gitignore`에서 제외합니다. API 키를 학생이나 다른 사람에게 알려주지 마세요.

## 4. 채점기준 작성 예시

문제: 식물의 광합성에 필요한 조건과 그 결과를 설명하세요.

배점: 10점

채점기준: 빛 2점, 물 2점, 이산화탄소 2점, 포도당 생성 2점, 산소 방출 2점. 언급한 요소별로 점수를 합산한다.

필수 요소는 한 줄에 하나씩 입력합니다.

```text
빛
물
이산화탄소
포도당 생성
산소 방출
```

‘구체적인 예를 2개 제시’, ‘계산 과정 표시’, ‘단위 기재’처럼 문제에서 반드시 요구한 것도 별도 요소로 적어 주세요. 배점 합계와 감점 규칙은 교사가 맞춰야 합니다. 앱은 필수 요소 체크만으로 점수를 자동 계산하지 않으며, AI는 작성한 기준에 따라 제안합니다.

## 5. 저장과 개인정보

- 앱에는 로그인, 학생별 데이터베이스, 자동 저장 기능이 없습니다. **현재 학생의 결과를 엑셀로 보관한 뒤** 다음 학생으로 바꿔 주세요.
- 문제·사진·학생 표시명·모델·모드를 바꾸거나 재채점하면 기존 결과와 확정이 초기화됩니다. 점수·근거·필수 요소 판단을 바꾸면 다시 확정해야 합니다. 관찰 기록을 바꾸면 세특을 다시 생성해야 합니다.
- 사진과 입력은 실행 중 서버 메모리에서 처리하고 앱이 별도 파일로 저장하지 않습니다. 새로고침·연결 종료·재시작 시 작업이 사라질 수 있습니다.
- 실제 채점은 문제·채점기준·사진을 OpenAI로 전송합니다. 세특 생성은 문항·교사 확정 평가(답안 증거 포함)·관찰 기록을 전송합니다. 학생 표시명은 AI 요청에서 제외하지만 사진·기록에 개인정보가 들어갈 수 있습니다. 제공업체의 데이터 처리 정책 및 학교 지침을 확인하세요.
- 엑셀에는 학생 표시명과 평가 기록이 들어갑니다. 학교가 허용한 장소에 안전하게 보관하세요.
- AI 점수는 제안, 세특은 초안입니다. 학생에 대한 최종 판단과 기록은 교사가 합니다. 체험 데이터는 실제 평가로 사용하지 마세요.

## 6. 문제 해결

- **설치 오류:** 인터넷 연결과 Python 버전을 확인하세요. `start.bat` 실행 창의 오류를 확인합니다. 학교망에서 패키지 다운로드가 차단될 수 있습니다.
- **AI 요청 실패:** API 키, API 잔액, 모델 사용 권한과 이미지·구조화 출력 지원, 인터넷 연결을 확인하세요. 화면에 비밀 키가 포함된 상세 서버 오류를 표시하지 않습니다. 입력은 유지되므로 다시 요청할 수 있습니다.
- **사진 인식 부정확:** 그림자·흐림·회전을 줄이고 해당 학생의 답안만 올리세요. JPG/PNG만 지원하며 PDF/HEIC는 변환해야 합니다.
- **점수는 바꿨는데 다운로드가 없음:** 검토 확인란을 다시 체크하고 최종 확정하세요.
- **결과가 사라짐:** 입력 변경은 이전 결과를 무효화합니다. 최종 결과를 엑셀로 내려받은 뒤 새 작업을 시작하세요.

## 개발 및 검증 (Linux / 클라우드)

각 클라우드 작업은 이미 격리되어 있으므로 기존 `/workspace/student-grading` 체크아웃을 사용하고 별도 Git worktree는 만들지 않습니다.

```bash
cd /workspace/student-grading
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m streamlit run app.py --server.address 0.0.0.0 --server.port 8501 --server.headless true
```

현재 범위: 학생 1명, 수동 문항 입력, 메모리 세션, OpenAI 연결, XLSX 출력. 여러 학생 일괄 처리·성적 시스템 연동·PDF 입력은 지원하지 않습니다.
